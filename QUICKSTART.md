# ⚡ Quick Start

## First Time Setup

```bash
# Install backend
cd backend && pip3 install -r requirements.txt --user && cd ..

# Install frontend  
cd frontend && npm install && cd ..
```

## Run the App

```bash
./start-webapp.sh
```

Open **http://localhost:3000** 🚀

---

## Separate Terminals (Alternative)

**Terminal 1:**
```bash
./start-backend.sh
```

**Terminal 2:**
```bash
./start-frontend.sh
```
